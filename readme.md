# StockHub

## 📋Descripción
Es un sistema de gestión de inventario desarrollado en Python que permite administrar de manera sencilla los productos registrados y controlar las cantidades disponibles en stock.
El sistema funciona mediante un menú interactivo desde la consola, facilitando el registro,consulta,búsqueda y eliminación de productos.

## 🚀Funcionalidades

### Ver stock:
Muestra todos los productos registrados junto con sus respectivas cantidades.

### Buscar producto:
Permite buscar un producto por su nombre y consultar la cantidad disponible.

### Eliminar producto:
Permite eliminar un producto registrado en el inventario.

### Salir:
Permite finalizar la ejecución del programa.

### Validación de búsqueda:
Informa al usuario cuando el producto que busca no se encuentra.

### Menú interactivo:
Permite acceder fácilmente a las diferentes funciones del sistema.

## 📝¿Cómo ejecutar?

1. Tener instalado Python en el computador.
2. Descargar o clonar el programa StockHub.
3. Abrir la carpeta del proyecto en Visual Studio Code.
4. Abrir una terminal.
5. Ejecutar el archivo principal, por ejemplo:
python stockhub.py
6. El sistema mostrará el menú.
7. Seleccionar una opción ingresando el número correspondiente.
